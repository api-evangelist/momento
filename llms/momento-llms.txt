# Momento

> Momento is a serverless data platform offering low-latency, pay-as-you-go infrastructure with nothing to provision, tune, or scale. Its core services are Momento Cache (serverless cache and drop-in Redis replacement), Momento Topics (serverless pub/sub event bus), and Momento Leaderboards (durable sorted sets). Access is over gRPC and a region-scoped HTTP API, authenticated with Momento API keys and short-lived disposable tokens.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Momento apis.yml and repository artifacts.

## Services
- [Momento Cache](https://docs.momentohq.com/cache): Low-latency ephemeral serverless cache; Redis-compatible.
- [Momento Topics](https://docs.momentohq.com/topics): Serverless publish/subscribe event bus.
- [Momento Leaderboards](https://docs.momentohq.com/leaderboards): Massive, durable sorted sets.

## APIs
- [Cache HTTP API reference](https://docs.momentohq.com/cache/develop/api-reference/http-api): GET/PUT/DELETE cache items over HTTP.
